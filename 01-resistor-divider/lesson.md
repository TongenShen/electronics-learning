# 第 01 课：电阻与欧姆定律 —— 从分压器开始

> 预计 1.5~2 小时｜前置：无（本课是起点）｜本课电路：[`divider.asc`](divider.asc) 等 6 张图
> 一句话目标：**能自己算出任意两个电阻的分压结果，并说清它什么时候不能用。**

## 1. 电阻在做什么

电流就是电荷在导体里流动。电阻的作用可以理解成"管道里的摩擦"：它**限制电流**，并把电能变成热散掉。

三个必须记住的定量关系（后面每节课都要用）：

```
欧姆定律：   V = I · R          （V 伏特，I 安培，R 欧姆）
电功率：     P = V · I = I²R = V²/R
串联：       R = R1 + R2 + …   （电流相同，电压按阻值分配）
并联：       1/R = 1/R1 + 1/R2 + …   （电压相同，电流按阻值分配）
两个并联：   R = R1·R2 / (R1+R2)
```

选电阻时不只看阻值，还要看三个参数：

| 参数 | 意义 | 什么时候会咬你 |
|---|---|---|
| 阻值 | 标称值，E24/E96 系列 | 需要精确比值时要选 E96（1% 系列） |
| 精度 | ±5%（碳膜）/±1%（金属膜） | 做精密分压、基准时要算误差 |
| **额定功率** | 直插 1/4W、贴片 0805 是 1/8W | **算错就冒烟**（见第 6 节） |

## 2. 分压器：本课的主角

电路结构（就是 `divider.asc` 那张图）：

```
Vin ──[ R1 ]──┬── out
              │
             [ R2 ]
              │
             GND
```

推导只用两步：

```
1) 串联电流处处相同：  I = Vin / (R1 + R2)
2) 输出取自 R2 两端：  Vout = I · R2

                        R2
   ==>    Vout = Vin · ─────────
                       R1 + R2
```

**两个关键结论**：

1. **分压比只由电阻之比决定**，与绝对阻值无关。10k:10k 和 1k:1k 都是分一半；但绝对阻值决定了**流过多少电流**（也就决定了费不费电）。
2. **从输出端看进去，这个电路等效于一个电压源加一个内阻**（戴维南定理）：

```
   Vth = Vin · R2/(R1+R2)        Rth = R1 ∥ R2 = R1·R2/(R1+R2)
```

这条是本课**最重要**的一句话——第 4.3 节的负载效应全靠它解释。

## 3. 怎么在 LTspice 里看结果（新手操作）

1. 双击 `.asc` 文件（你本机已装 LTspice 24）；工具栏那个**跑步小人**（或菜单 `Simulate → Run`）就是"开始仿真"
2. `.dc` / `.tran` 这类分析：跑完会弹出波形窗口——**点电路里的导线**看该节点电压，**点元件**看流过它的电流
3. `.op`（静态工作点）和 `.meas`（测量语句）的结果在菜单 `View → SPICE Error Log` 里
4. 看到 `Direct Newton iteration for .op point succeeded` 就说明算通了；`.meas` 的数值会紧跟其后

> 小技巧：波形窗口里点节点名可以改标签；`Ctrl` + 左键点节点名能看该点的电压表达式。

## 4. 四个实验

### 4.1 空载分压：`divider.asc`

电路：Vin = 12 V，R1 = R2 = 10 kΩ。

先**自己算一遍再跑**：

```
I    = 12V / (10k + 10k) = 12 / 20k = 0.6 mA
Vout = 0.6mA × 10k = 6 V
```

仿真实测（`.meas` 输出）：

```
V(out) = 6 V              与手算完全一致
I(V1)  = -0.6 mA          负号只是 LTspice 把"电流从正极流出"记为负，大小是 0.6 mA
```

### 4.2 线性关系：`divider_dc.asc`

这张图把输入电压从 0 扫到 12 V（`.dc V1 0 12 1`）。在波形窗口里画出 `V(out)`，你会看到一条**过原点的直线，斜率 1/2**。

结论：理想电阻的分压比不随输入变化——这就是"分压器可以当电压采样"的前提。

### 4.3 负载效应（本课重点）：`divider_load_1k / _10k / _100k.asc`

现在在输出端并联一个负载电阻 RL（模拟"真的接了东西"），同时接上负载后 R2 变成了 `R2 ∥ RL`：

```
                 R2 ∥ RL
   Vout = Vin · ─────────────
                R1 + R2 ∥ RL
```

三张图的仿真实测：

| RL | R2∥RL | 公式值 | 仿真值 | 相对空载 6 V 的误差 |
|---|---|---|---|---|
| 空载（∞） | 10 kΩ | 6.000 V | **6.000 V** | 0 |
| 100 kΩ | 9.091 kΩ | 5.714 V | **5.714 V** | −4.8% |
| 10 kΩ | 5.000 kΩ | 4.000 V | **4.000 V** | −33% |
| 1 kΩ | 0.909 kΩ | 1.000 V | **1.000 V** | −83% |

再用戴维南等效**换一条路算**（应该得到同一个数，验证你理解了）：

```
Vth = 6 V,  Rth = 10k ∥ 10k = 5 kΩ
RL = 1k :  Vout = 6V × 1k/(5k+1k) = 1.0 V     ← 与上表一致
RL = 10k:  Vout = 6V × 10k/(5k+10k) = 4.0 V   ← 一致
```

**这就是"分压器不能当电源用"的量化解释**：它有一个 5 kΩ 的内阻，负载一拉电流，电压立刻塌下去。

### 4.4 参数扫描：`divider_load_step.asc`

这张图用 `.step param RL list 1k 10k 100k` 一次跑三档。在 GUI 里 Run 之后，波形窗口会**画出三条不同颜色的曲线**，一眼就能看出负载越重、输出越低。

> ⚠️ 一个工具坑（我踩过）：批处理模式（`LTspice.exe -b`）下 `.step` 配合 `.meas` 只会报**最后一组**结果，所以本课的实测数据取自三张固定值的图，而不是这张扫描图。想做自动批处理验证时，一张图只放一个工况最稳。

## 5. 什么时候能用、什么时候不能用

| 场景 | 能用吗 | 原因 |
|---|---|---|
| 给 ADC 采样一个电压 | ✅ | ADC 输入阻抗极高（MΩ 级），几乎不取电流 |
| 给比较器/运放设阈值电压 | ✅ | 输入阻抗高，负载轻 |
| 给三极管基极做偏置 | ✅ | 基极电流小（µA 级） |
| **给 LED、继电器、单片机供电** | ❌ | 负载重，电压塌陷；而且空载也持续耗电 |
| 需要稳定电压 | ❌ | 输入或负载一变，输出就跟着变（没有反馈） |

**经验判据**：负载电阻至少要比分压器输出阻抗（Rth）大 **10 倍**，输出误差才小于约 10%。用表格里的数据自己验算一下：

```
误差 ≈ Rth / (Rth + RL)
RL = 100k : 5k/105k = 4.8%   ✔ 可用
RL = 10k  : 5k/15k  = 33%    ✘ 已经不能用了
```

## 6. 功率核算：别把电阻烧了

本课电路里每个电阻的功耗：

```
P = I²R = (0.6mA)² × 10k = 3.6 mW        ← 连 0805（1/8W = 125mW）的 3% 都不到，随便用
```

但换一组值就是另一个故事：

```
如果把 12V 直接加在 1 kΩ 上：P = 12²/1000 = 144 mW  ← 0805（125mW）会烧，必须换 1/4W 直插
```

**选型习惯**：算出实际功耗后，选**额定功率 ≥ 2 倍**的电阻。

## 7. 自测题（先自己算，再看答案）

1. 12 V 经 R1 = 4.7 kΩ（上）、R2 = 2.2 kΩ（下）分压，求 Vout 和电流。
2. 在第 1 题输出端接一个 10 kΩ 负载，Vout 变成多少？分别用"R2∥RL"和"戴维南等效"两种方法算。
3. 想把 12 V 分压成 3.3 V，且分压支路电流约 1 mA，R1、R2 取多少？（提示：E24 系列有 3.3k、8.2k、9.1k；E96 有 8.66k）
4. 为什么分压器不能直接给 5 V 单片机供电？至少说两条理由。
5. 一个 0805 电阻（额定 1/8 W），如果阻值是 1 kΩ，最多允许流过多大电流？

<details>
<summary>答案（点开）</summary>

1. `I = 12/(4.7k+2.2k) = 1.739 mA`；`Vout = 1.739mA × 2.2k = 3.83 V`
2. 并联法：`R2∥RL = 2.2k×10k/(2.2k+10k) = 1.803 kΩ`，`Vout = 12 × 1.803/(4.7+1.803) = 3.33 V`
   戴维南法：`Vth = 3.83 V`，`Rth = 4.7k∥2.2k = 1.499 kΩ`，`Vout = 3.83 × 10/(1.499+10) = 3.33 V` ✔ 两法一致（误差 13%，已经偏大，说明该用更低阻值的分压或加缓冲）
3. `R总 = 12V/1mA = 12 kΩ`，`R2 = 3.3V/1mA = 3.3 kΩ`，`R1 = 12k − 3.3k = 8.7 kΩ`
   实际选 E96 的 **8.66 kΩ**（Vout ≈ 3.31 V）或 E24 的 **9.1 kΩ**（Vout ≈ 3.19 V）——这就是"理论值"和"能买到的值"的差距
4. ①输出阻抗高（几 kΩ），负载一取电流电压就掉；②没有反馈，输入波动/负载变化都会直接传到输出；③空载也一直耗电，效率低；④给不出大电流
5. `P = I²R` → `I = √(P/R) = √(0.125/1000) = 11.2 mA`（对应压降 11.2 V）。按 2 倍余量的工程习惯，实际用到 **5~6 mA** 以内更稳。

## 8. 本课小结（三句话）

1. 欧姆定律 + 串并联 + 分压公式 `Vout = Vin·R2/(R1+R2)` 是后面所有电路的地基。
2. **分压器的输出不是理想电压源**，它的内阻是 `R1∥R2`，负载必须远大于这个内阻（≥10 倍）才不掉压。
3. 电阻要同时核算**阻值、精度、功率**三件事，只算阻值是新手最容易冒烟的地方。
