# Electronics Learning —— 从元器件原理开始的电路仿真课

用 **LTspice 仿真 + 可复现的电路文件**，把电子信息类专业的硬件基础一条线学下来。

每节课 = 一个文件夹 = 一篇教程（`lesson.md`）+ 一组**能直接打开就跑**的 LTspice 原理图（`.asc`）。

> 起点：软件基础（C / Linux）已经过关，但硬件从零开始。
> 做法：**先自己算 → 跑仿真对答案 → 改参数看趋势**，而不是看视频抄公式。

## 这个项目适合谁

- 电子信息 / 自动化 / 通信等专业的低年级学生
- 会写点代码、但没真正碰过电路的人
- 想用仿真验证公式、而不是死记硬背的人

不需要实验室、不需要买元件——一台电脑 + LTspice 就能跑完全部课程。

## 怎么用

1. **读**：打开某课的 `lesson.md`，先看原理推导（为什么）
2. **算**：看到电路参数，**先自己在纸上算出结果**——这一步最容易被跳过，但最有用
3. **跑**：双击同目录的 `.asc`，在 LTspice 里按跑步小人（`Simulate → Run`），和自己的答案对一下
4. **改**：改电阻/电容值再跑一遍，看趋势是否符合公式（猜错了才是真收获）
5. **测**：做 `lesson.md` 末尾的自测题

几个新手常踩的坑，先记着：

- **出表还是出图，取决于电路里的仿真指令**：`.op` 只求一个静态解（结果在 `View → SPICE Error Log`），`.tran` / `.dc` / `.ac` 才有波形窗口
- **探针只在有波形时可用**：波形窗口里点导线看电压、点元件看电流
- 纯电阻 + 直流源跑 `.tran` 得到的是一条**水平直线**——曲线的形状来自储能元件（C/L）或时变源（SINE/PULSE）

每节课的文件分三类：

| 类型 | 作用 | 你需要会吗 |
|---|---|---|
| `.md` | 教程与实验说明 | 要读 |
| `.asc` | LTspice 原理图，双击就能跑 | 会打开、会改数值即可 |
| `gen_*.py`、`.log`、`.net` | 生成图纸的脚本、批处理仿真的验证记录 | 不必会写，能对照结果就行 |

| **LTspice 24.x**（免费） | 在 [ADI 官网](https://www.analog.com/en/resources/design-tools-and-calculators/ltspice-simulator.html) 下载；本项目在 Windows 11 + LTspice 24.1.9 上验证 |

## 这些电路是怎么画出来的

图纸不是手工拖出来的，而是由 Python 脚本用一套自研绘图库（`ltspice-builder`）生成：

- 读取 LTspice 自带符号库的引脚坐标 → 按放置方向做旋转/镜像变换 → 用 `WIRE` 连线 → 写出 `.asc`
- 图纸是**纯文本**：可版本管理、可参数化、可批量重画
- 生成后统一用批处理仿真验证：`LTspice.exe -b <file>.asc`，退出码 0 且日志出现 `Direct Newton iteration ... succeeded` 才算通过

**教程里的每一个数值都来自实测**（`.log` 里 `.meas` 语句的输出），不是抄来的理论值。

绘图布局约定：元件之间留足空白；任意两个元件的引脚之间一律经过一段导线连接（不允许引脚坐标直接对接）。

## 学习节奏建议

每课约 1.5~2 小时：

- 30 min 读原理（`lesson.md` 前半）
- 40 min 自己跑仿真、观察波形，**先自己猜数值再看结果**
- 30 min 改参数实验（改电阻/电容/频率，看趋势是否符合公式）
- 20 min 自测题 + 用自己的话写下这一课的三个结论
